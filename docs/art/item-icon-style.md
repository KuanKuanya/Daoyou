# 物品图片风格基准

以青玉灵露瓶 `item-origin-dew-ink-v2.webp` 为样式参考。同一批优先生成精灵图，再按透明间隔切图，保持笔墨和色彩一致。

- 传统中国水墨与轻矿物色，暖灰墨线，清透浅色面，克制的枯笔。避免厚黑团、卡通高光或3D质感。
- 玉石以低饱和青绿／青蓝为主，纸布用暖米色，木质用浅赭色，果实与符纹可少量朱红。
- 宽而清楚的完整轮廓、克制细节、自然视角与左上明暗；通过形状区分道具类别，品级保留原有名称颜色。
- 透明背景，不画阴影、光晕、粒子、徽章、边框或文字。
- 切图前测量 alpha 间隔，检查完整轮廓与邻格污染；生成图片不一定严格遵守数学网格。
- 生产图片统一 256×256 透明无损 WebP，主体等比限制在224×224范围，至少16px安全边距。
- 复核24／32／40px纸色预览，并检查桌面与360px手机。未完成的检查明确记录。
- 在集中图标注册表与物品摘要适配器接入，复用现有 GameIcon、物品格与预览；保留字号、格子、品质颜色、数量和交互。

最新九类专属道具来自同一3×3精灵图；完整提示词与切图坐标见 [精灵图记录](item-sprite-atlas-2026-10-07.json)。实际项目参考图位于 `apps/web/public/assets/icons/item-origin-dew-ink-v2.webp`。
