# 游戏背景音乐

## 资源与配置

- 正式音频目录：`apps/web/public/assets/audio/bgm/`。当前《问道虚空》从临时“音频资源”目录移入，文件名为 `wendao-xukong-v1.mp3`，保留原音频质量。
- 曲目与场景绑定唯一来源：`apps/web/src/lib/audio/bgm.json`。曲目 ID 稳定，替换文件使用新的版本文件名，避免浏览器复用旧响应。
- 第一版修行、游历、战斗共用一首音乐；相同曲目跨页面不重播。排行榜、战绩列表、组队大厅不使用战斗分类；`bgm.ts` 按现有场景 ID 归类，实际 `CombatV6Battle` 展示期间覆盖为战斗音乐（包括野外、练功房、秘境内战斗），离开展示恢复场景音乐。后续新增特殊场景时核对该映射。
- `source` 记录素材来源，`license` 记录授权情况。作者提供不等于授权已确认；发行前确认授权。工作台将“待确认”列为检查提示，不影响本地开发试听。

## 播放边界

`GameLayout` 下的 `BgmProvider` 持有一个游戏生命周期播放器；页面与 Phaser 不自行播放背景音乐。离开游戏释放音频与 AudioContext。原生媒体元素流式加载、循环，Web Audio GainNode 控制音量与 1.5 秒切歌淡入淡出，不把完整 MP3 解码进内存。

背景音乐默认关闭，音量默认 25%，沿用浏览器本地 game-setting 存储；关闭时不创建播放器、不加载音频。记住开启状态后，刷新仍等待用户手势解锁播放。设置页提供显式播放／重试按钮；底部公共导航提供快捷开关。音量归零暂停，恢复音量接着播放。

页面隐藏或失去焦点暂停，回到前台仅恢复已开启的音乐。同源游戏标签页通过 BroadcastChannel 争取播放权，新页面开始播放时暂停其他页面。工作台与游戏端口不同，不共享该通道；工作台试听与游戏均在失去焦点时暂停。移动端系统中断和自动播放权限变化可能需要再次点击播放，不保证系统允许后台播放。

音频在 Service Worker 中使用 NetworkOnly，排在通用 `/assets/` 媒体缓存规则之前，保留服务器 Range 响应，不预缓存曲目、不承诺离线音乐。未来做离线缓存需单独处理完整文件、Range 和容量限制。

## 开发管理

工作台“背景音乐”页可以试听、查看时长与体积，注册／移除未绑定的曲目、替换已有文件绑定、调节音量校准、编辑来源和授权、配置三个场景的曲目。音量校准为 0–100%，与玩家音量相乘；工作台试听采用曲目校准音量。

新增文件先放进正式目录，使用 ASCII 文件名；工作台支持 MP3、OGG、WAV、M4A 文件选择，是否能播放取决于文件实际编码和浏览器支持。工作台不上传或生成音频，不修改音频波形，不删除素材文件。

保存显示确认信息，校验完整配置、已存在资源和源文件 SHA-256；复用工作台串行写入与会话内撤销。配置解析失败只影响音乐管理页，检查报告保留错误，可通过新增曲目重建配置。游戏开发环境会热更新配置，必要时刷新；生产需重新构建并部署 Web。

## 验收

按 `docs/testing.md` 在本地页面核对默认关闭、手势开启、音量归零与恢复、跨页面连续播放、刷新后恢复、双标签页互斥、离开游戏停止、工作台试听与保存撤销。检查桌面和 360px 页面。运行 lint、typecheck、Web build；此功能属于浏览器集成，不在应用目录新增单元测试。
