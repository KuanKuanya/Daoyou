# Phase 10AB：通用自动战斗策略底座

> 2026-09-11；首版底座与场景接入已实现，完成共享测试和重点本地验收。10AA明确跳过，其遗留项不视为完成。本阶段未发布。

## 1. 已确认边界

- 主动AUTO、天骄榜等非实时对战副本、所有NPC敌人使用公共效用策略。所有NPC包含此前固定普攻、防御或技能轮换的敌人，以用户最后确认覆盖早期保留建议。
- 玩家手动下令、擂台超时补令、客户端3秒请求一次AUTO、离页／刷新回手动保持现状；不增加离线托管。
- 内部均衡／进攻／保守预设，线上入口默认均衡；不开放策略选择页面。
- 不自动换宠、逃跑、捕捉或用药，不做全队托管、Boss行为树、多回合搜索或数值平衡。
- 蜃楼周进度仍只保存Redis，不新增持久周进度或结算账本。

## 2. 实现职责

共享应用层 `packages/shared/src/combat-v6`：

| 模块 | 职责 |
| --- | --- |
| auto-observation | 按控制者过滤战局；仅自身及所控灵兽精确数据，其余单位公开血蓝万分比、状态及护盾，隐藏属性按观察者基线估算 |
| auto-utility | 普攻／防御及合法技能候选，输出／生存／控制／成本评分，固定排序与有限目标组合 |
| auto-policy | 算法和参数联合版本、三种权重预设 |
| auto | 保留公共单次调用入口、已有本方指令、人物与灵兽的短期意图折扣、可选内部解释 |

评分器只接收过滤后的观察和本单位合法选项，不读取原战局指令、敌方构筑、随机数。合法选项由现有引擎查询产生，执行时仍由引擎复核。隐藏最大气血、攻防和等级不会因为服务端可读而参与评分。旧 `npcStrategies` 保留内容／快照结构，Host不再按其普攻／防御／轮换分支执行。

复用规则公式与效果条件匹配，不模拟结算或消耗随机数。有效伤害／恢复按最大气血归一；击倒、复活和状态按行动价值启发式估算；成本按法力、气血和技能资源比例归一。随机分支按概率计收益。已计划的伤害／治疗折半计入，重复控制／复活降权，不假定已经命中。

首版不完整推演被动、反击、复杂成功链和未来回合。无法估算的额外效果不计收益并写入内部说明。解释数据默认不入库、不返回前端。首版结果不代表最优战术或宗门平衡结论。

## 3. 场景与版本

公共AUTO覆盖练功房、野外、秘境、蜃楼、宗门任务、突破、擂台主动AUTO；公共PvE Host覆盖NPC及非实时对手副本；天骄榜双方先生成本回合决策，再提交执行。

战斗版本新增可选 `autoPolicyVersion`，新场次记录 `combat_auto_utility_v1`（包括预设权重）。归档旧版本字段可缺省，回放不重新决策。旧运行态版本不匹配时拒绝恢复，不静默套用新策略。

上线先在旧版本停止新开战，处理完旧活动战局和未完成榜单挑战后切换；不以删除Redis键代替结算。该维护动作未在本阶段执行，且不恢复被跳过的10AA发布基线工作。

## 6. 2026-10-12：当前 v5 策略修正

当前自动战斗实现位于 `packages/game-rules/src/combat/`，策略版本为 `combat_auto_rules_v5`，版本常量由 `packages/game-domain/src/combat/auto-policy.ts` 持有。前文保留首版实现路径、版本及历史验收记录；本节记录当前代码的修正边界。

- **未知面板使用等级中性基线。** `auto-observation.ts` 依据控制者等级的公共成长预算，均分自由属性点并投影中性人物面板，用于估算非所控单位。敌方隐藏等级、装备、加点和真实攻防仍不参与评分，主人自身装备、加点和临时增益也不再左右这一基线。公开血蓝比例、状态及护盾继续沿用观察边界；自身与所控灵兽保留精确面板。
- **普攻与主动技能统一估值。** `auto-utility.ts` 将普攻作为内建物理攻击交给同一套效果评估，统一计入目标护盾、有效气血伤害和击倒收益，避免普攻绕过护盾而与技能评分失真。合法技能选项仍来自引擎查询，缺蓝、控制、冷却及目标合法性由引擎判断并在执行时复核；普攻已经足够击倒目标时仍可省蓝。
- **纳入已知自身的直接伤害收益。** `auto-strike.ts` 估算已知自身、条件匹配的标量 `onCritRoll`／`onHitCalc` 声明、暴击率与暴击倍率修正、伤害状态和法术波动均值。灵法精通、灵法会心、符合引擎资格的整法连击，以及普通物理连击的物伤代价与一次追加进入评分；按声明与观察信息判断，不按物种固定指定攻宠或法宠。
- **先处理结果边界，再求期望。** 暴击、命中和一次重复攻击保留独立概率分支，各分支先扣护盾、按剩余气血封顶并判断击倒收益，再按概率加权。普通物理连击要求首击造成气血伤害，追加仍计自身命中概率；首击已经击倒目标时不虚增重复伤害。灵法连击沿用引擎的伤害法术资格，不将重复当成额外一次法力支出，也不重复计算辅助效果。
- **保守处理未知限次可用性。** 观察对象不包含触发记录 `marks`，无法确认 `oncePerRound`／`oncePerBattle`／`oncePerActionTarget` 是否已经消耗，因此此类标量收益保守跳过；不以缺少记录推断限次收益仍可使用。

本版仍采用单次行动启发式：多段伤害聚合、波动均值、复杂条件链、反击及未来回合收益保留近似，不完整模拟战斗结算或消耗随机数。本次修正自动决策估值与策略版本，没有改变物种定位、实际伤害规则或 UI；前文历史验收不作为本版全量场景验收结论。
